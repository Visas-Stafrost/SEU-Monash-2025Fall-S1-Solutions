第十部分：PPT大题逐题详解——树的节点着色（最大化黑色节点数）
一、题目重现
对一棵以r为根的树进行节点着色，每个节点可着黑色或白色，约束条件为：相邻节点不能着相同黑色，但可着相同白色。要求设计算法，使树中被着黑色的节点数量尽可能多。
二、考点定位
树形动态规划（核心考查：树的后序遍历、节点状态的递归转移、子问题的最优合并）
三、解题思路拆解
树是递归结构，每个节点的着色选择依赖其子节点的状态，因此采用后序遍历+状态分类的动态规划思路：
状态定义：
对每个节点u，定义两种状态：
dp[u][0]：节点u着白色时，以u为根的子树中最大黑色节点数。
dp[u][1]：节点u着黑色时，以u为根的子树中最大黑色节点数。
转移方程：
若u着黑色（dp[u][1]）：
相邻子节点v不能着黑色，只能着白色，因此dp[u][1] = 1 + Σdp[v][0]（1是u自身的黑色计数，子节点取白色状态的最大值）。
若u着白色（dp[u][0]）：
相邻子节点v可选择着黑色或白色，取两者中的最大值，因此dp[u][0] = Σmax(dp[v][0], dp[v][1])。
遍历顺序：
采用后序遍历（先处理所有子节点，再处理当前节点），保证计算dp[u]时，子节点的dp[v]已计算完成。
最终结果：
根节点r的两种状态的最大值，即max(dp[r][0], dp[r][1])。
四、详细步骤推导（以示例树为例）
示例树：根r有两个子节点a和b，a有一个子节点c。
处理叶子节点c：
dp[c][1] = 1（c着黑，无子嗣）。
dp[c][0] = 0（c着白，无子嗣）。
处理节点a：
dp[a][1] = 1 + dp[c][0] = 1 + 0 = 1（a着黑，c必须着白）。
dp[a][0] = max(dp[c][0], dp[c][1]) = max(0,1) = 1（a着白，c选着黑）。
处理叶子节点b：
dp[b][1] = 1，dp[b][0] = 0。
处理根节点r：
dp[r][1] = 1 + dp[a][0] + dp[b][0] = 1 + 1 + 0 = 2（r着黑，a、b必须着白）。
dp[r][0] = max(dp[a][0], dp[a][1]) + max(dp[b][0], dp[b][1]) = max(1,1) + max(0,1) = 1 + 1 = 2（r着白，a选最大1，b选着黑1）。
最终结果：max(2,2) = 2（两种着色方案的黑色节点数均为2）。
五、答案呈现
树形DP代码框架（递归后序遍历）
六、改编思路拓展
改编方向1：节点带权重
题目修改：每个节点着黑色的权重不同（如节点u着黑得w[u]分，着白得0分），求总权重最大。
解题调整：状态定义改为dp[u][1] = w[u] + Σdp[v][0]，其余逻辑不变。
改编方向2：相邻节点不能同色（黑白均不可同）
题目修改：相邻节点不能着相同颜色（黑/白都不行），求最大黑色节点数。
解题调整：dp[u][0]的转移改为“子节点必须着黑”，即dp[u][0] = Σdp[v][1]，其余逻辑适配。
改编方向3：多颜色着色
题目修改：节点可着3种颜色（黑、白、灰），约束为“相邻节点不能同黑”，求最大黑色节点数。
解题调整：状态增加“着灰”，dp[u][2]表示着灰时的最大黑数，转移时子节点可自由选非黑状态。
第十一部分：PPT大题逐题详解——字符串分词（最大化质量和）
一、题目重现
给定长字符串y = y₁y₂…yₙ，分词是将其切分为若干连续子串，每个子串为合法词汇。函数quality(x)返回词汇x的质量（值越高越优），分词的总质量为所有子串质量之和。要求设计动态规划算法，找到总质量最大的分词方案。
二、考点定位
线性划分型动态规划（核心考查：前缀状态定义、切分点的遍历与转移）
三、解题思路拆解
这是典型的划分型DP，通过前缀状态覆盖所有可能的切分方式：
状态定义：
dp[i]表示“字符串前i个字符（y₁…yᵢ）的最大分词质量和”。
转移方程：
对于第i个字符，枚举所有可能的切分点j（j从0到i-1），即前j个字符已分词，第j+1到i个字符为一个词汇，因此：
dp[i] = max(dp[j] + quality(y[j+1..i]))（j ∈ [0, i-1]）
初始化：
dp[0] = 0（空字符串的质量和为0）。
计算顺序：
按i从1到n遍历（前缀长度递增），保证计算dp[i]时，所有dp[j]（j < i）已计算完成。
最终结果：
dp[n]（整个字符串的最大质量和）。
四、详细步骤推导（以示例字符串为例）
示例：字符串y = "abc"，假设quality函数为：
quality("a")=1，quality("ab")=3，quality("abc")=4
quality("b")=1，quality("bc")=2
quality("c")=1
初始化：dp[0] = 0。
计算dp[1]（前1个字符“a”）：
仅切分点j=0：dp[1] = dp[0] + quality("a") = 0+1=1。
计算dp[2]（前2个字符“ab”）：
枚举j=0和j=1：
j=0：dp[0] + quality("ab") = 0+3=3
j=1：dp[1] + quality("b") = 1+1=2
取最大值：dp[2] = 3。
计算dp[3]（前3个字符“abc”）：
枚举j=0、j=1、j=2：
j=0：dp[0] + quality("abc") = 0+4=4
j=1：dp[1] + quality("bc") = 1+2=3
j=2：dp[2] + quality("c") = 3+1=4
取最大值：dp[3] = 4。
五、答案呈现
划分型DP代码框架
六、改编思路拓展
改编方向1：限制切分次数
题目修改：分词次数不超过k次（即最多切分为k+1个词汇），求最大质量和。
解题调整：状态定义为dp[i][t]（前i个字符切分t次的最大质量和），转移方程为dp[i][t] = max(dp[j][t-1] + quality(y[j+1..i]))，初始化dp[0][0] = 0。
改编方向2：质量函数含惩罚项
题目修改：若子串不是合法词汇，quality(x)返回负数（惩罚），要求避免无效切分。
解题调整：转移时需判断quality(substring)是否为正，仅保留有效切分（或直接纳入计算，让DP自动选择最优）。
改编方向3：多词典分词
题目修改：有多个词典（如通用词典、专业词典），不同词典的quality函数不同，求最大总质量。
解题调整：状态定义增加词典维度dp[i][d]（前i个字符用词典d的最大质量和），转移时可切换词典。
第十二部分：PPT大题逐题详解——带权活动选择问题
一、题目重现
给定n个活动，每个活动aᵢ表示为三元组(sᵢ, fᵢ, vᵢ)，其中sᵢ是开始时间，fᵢ是结束时间，vᵢ是权重。要求选择若干活动，满足任意两个选中活动的时间区间不重叠，且选中活动的权重和最大。
二、考点定位
动态规划+贪心排序（核心考查：活动排序、前驱活动查找、状态转移的最优合并）
三、解题思路拆解
经典的带权活动选择问题，需结合排序+前驱查找+DP解决：
预处理：按结束时间排序
先将所有活动按结束时间fᵢ升序排列，保证后续能通过二分查找快速找到不重叠的前驱活动。
状态定义：
dp[i]表示“前i个活动（排序后的前i个）的最大权重和”。
前驱活动查找：
对第i个活动aᵢ，找到最后一个结束时间≤sᵢ的活动k（即与aᵢ不重叠的最大索引k），记为prev[i]。可通过二分查找f数组实现。
转移方程：
对第i个活动，有两种选择：
不选aᵢ：dp[i] = dp[i-1]。
选aᵢ：dp[i] = dp[prev[i]] + vᵢ。
因此dp[i] = max(dp[i-1], dp[prev[i]] + vᵢ)。
初始化：
dp[0] = 0（无活动时权重和为0）。
最终结果：
dp[n]（所有活动的最大权重和）。
四、详细步骤推导（以示例活动为例）
示例活动（排序前）：
步骤1：按结束时间排序
排序后活动顺序：a₂(2,3,2) → a₁(1,4,3) → a₃(5,7,4) → a₄(6,8,5)。
结束时间数组f = [3,4,7,8]。
步骤2：预处理前驱prev数组
a₂（i=1）：无结束时间≤2的活动，prev[1] = 0。
a₁（i=2）：找结束时间≤1的活动，无，prev[2] = 0。
a₃（i=3）：找结束时间≤5的活动，最大索引是2（a₁的f=4≤5），prev[3] = 2。
a₄（i=4）：找结束时间≤6的活动，最大索引是2（a₁的f=4≤6），prev[4] = 2。
步骤3：计算dp数组
dp[0] = 0。
dp[1] = max(dp[0], dp[prev[1]] + v₂) = max(0, 0+2) = 2。
dp[2] = max(dp[1], dp[prev[2]] + v₁) = max(2, 0+3) = 3。
dp[3] = max(dp[2], dp[prev[3]] + v₃) = max(3, 3+4) = 7。
dp[4] = max(dp[3], dp[prev[4]] + v₄) = max(7, 3+5) = 7。
最终结果：dp[4] = 7（选中a₁和a₃，权重和3+4=7）。
五、答案呈现
带权活动选择代码框架
六、改编思路拓展
改编方向1：活动可重叠k次
题目修改：允许最多k个活动同时进行（如k=2表示场地有2个），求最大权重和。
解题调整：状态定义为dp[i][t]（前i个活动，同时进行t个的最大权重和），转移时判断t是否小于k。
改编方向2：活动有依赖关系
题目修改：部分活动需在指定活动完成后才能开始（如a₃需在a₁结束后开始），求最大权重和。
解题调整：预处理依赖关系，转移时需满足依赖条件（如选a₃前必须选a₁）。
改编方向3：活动持续时间可变
题目修改：活动的结束时间fᵢ可调整（如fᵢ = sᵢ + dᵢ，dᵢ是可选的持续时间），不同dᵢ对应不同权重vᵢ(d)，求最大权重和。
解题调整：状态定义增加持续时间维度dp[i][f]（前i个活动，最后结束时间为f的最大权重和），转移时选择dᵢ并更新f。

def tree_coloring(root):
    # 初始化dp数组，用字典存储每个节点的(白,黑)状态
    dp = {}
    def post_order(u):
        # 初始状态：叶子节点
        dp[u] = [0, 1]  # [着白的最大黑数, 着黑的最大黑数]
        for v in u.children:  # 遍历所有子节点
            post_order(v)
            # 转移：着黑时，子节点必须着白
            dp[u][1] += dp[v][0]
            # 转移：着白时，子节点选最大状态
            dp[u][0] += max(dp[v][0], dp[v][1])
    post_order(root)
    return max(dp[root][0], dp[root][1])

def max_quality_segmentation(y, quality):
    n = len(y)
    dp = [0]*(n+1)  # dp[0]=0，dp[i]对应前i个字符
    for i in range(1, n+1):
        max_val = -float('inf')
        # 枚举所有可能的切分点j
        for j in range(i):
            # 切分j+1到i的子串
            substring = y[j:i]
            current = dp[j] + quality(substring)
            if current > max_val:
                max_val = current
        dp[i] = max_val
    return dp[n]

def weighted_activity_selection(activities):
    n = len(activities)
    # 步骤1：按结束时间升序排序
    activities.sort(key=lambda x: x[1])
    f = [act[1] for act in activities]  # 结束时间数组
    v = [act[2] for act in activities]  # 权重数组
    s = [act[0] for act in activities]  # 开始时间数组
    
    # 步骤2：预处理prev数组（二分查找前驱）
    prev = [0]*n
    for i in range(n):
        # 找最大的k，使得f[k] <= s[i]
        low, high = 0, i-1
        best = -1
        while low <= high:
            mid = (low + high) // 2
            if f[mid] <= s[i]:
                best = mid
                low = mid + 1
            else:
                high = mid - 1
        prev[i] = best + 1  # 对应dp的索引（dp从1开始）
    
    # 步骤3：计算dp数组
    dp = [0]*(n+1)
    for i in range(1, n+1):
        # 不选第i个活动：dp[i-1]；选第i个活动：dp[prev[i-1]] + v[i-1]
        dp[i] = max(dp[i-1], dp[prev[i-1]] + v[i-1])
    return dp[n]

# 测试示例
activities = [(1,4,3), (2,3,2), (5,7,4), (6,8,5)]
print(weighted_activity_selection(activities))  # 输出7
