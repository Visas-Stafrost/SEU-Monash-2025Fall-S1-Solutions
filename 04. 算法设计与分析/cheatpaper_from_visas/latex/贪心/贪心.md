### 第一部分：贪心算法解题的“固有方法论”

贪心算法（Greedy Algorithm）的核心思想是：**只顾眼前，不顾未来**。在每一步选择中都采取在当前状态下最好（局部最优）的选择，从而希望导致结果是全局最优的。

**解题四步法**：

1. **贪心策略选择 (Greedy Choice)**：
   - 思考：用什么标准来做“贪心”？（例如：选最贵的？选结束最早的？选单位价值最高的？）
   - 技巧：通常需要对数据进行**排序**或使用**优先队列**。
2. **可行性检查 (Feasibility Check)**：
   - 思考：这个选择是否满足限制条件？（例如：背包满了吗？时间冲突了吗？）
3. **子问题化 (Sub-problem)**：
   - 做完一个选择后，原问题变成了什么样？（通常是规模变小的同类问题）。
4. **证明/验证 (Proof/Verify)**：
   - (解题时可选) 尝试举反例，如果举不出反例，通常策略是正确的。常见的证明方法是“交换论证法”。

#### 1. 分数背包问题 (Fractional Knapsack)

**题目**：物品 $(P_i, W_i)$，背包容量 $M$，物品可部分装入，求最大价值。

- **贪心策略**：优先选择**单位重量价值** ($v_i = P_i / W_i$) 最高的物品。
- **复杂度**：$O(N \log N)$ (排序时间)。

**代码实现 (C++)**：

C++

```
struct Item { int id; double p, w, ratio; };
bool cmp(Item a, Item b) { return a.ratio > b.ratio; } // 按性价比降序

void solve_knapsack(int n, double M, vector<double> P, vector<double> W) {
    vector<Item> items(n);
    for(int i=0; i<n; ++i) items[i] = {i, P[i], W[i], P[i]/W[i]};
    sort(items.begin(), items.end(), cmp);

    vector<double> X(n, 0.0);
    double totalVal = 0;
    
    for(int i=0; i<n; ++i) {
        if(items[i].w <= M) { // 拿光
            X[items[i].id] = 1.0;
            totalVal += items[i].p;
            M -= items[i].w;
        } else { // 拿部分，装满背包
            X[items[i].id] = M / items[i].w;
            totalVal += items[i].p * X[items[i].id];
            break; // 背包满了
        }
    }
    // 输出 X 和 totalVal
}
```

#### 2. 带截止时间的作业调度 (Job Sequencing with Deadlines)

**题目**：$n$ 个作业，单位时间完成，截止时间 $d_i$，收益 $p_i$。求最大收益。

- **贪心策略**：优先选择**收益 $p_i$ 最大**的作业。
- **策略执行**：将作业按收益降序排序。对于每个作业，尝试将其安排在**不超过截止时间的最晚空闲时间槽**（尽可能晚做，把前面的时间留给截止时间更紧迫的作业）。
- **复杂度**：$O(N^2)$ (简单查找空位) 或 $O(N \log N)$ (使用并查集优化查找)。

**代码实现 (C++)**：

C++

```
struct Job { int id, d, p; };
bool cmp(Job a, Job b) { return a.p > b.p; } // 按收益降序

int solve_jobs(int n, vector<Job>& jobs) {
    sort(jobs.begin(), jobs.end(), cmp);
    int max_deadline = 0;
    for(auto& j : jobs) max_deadline = max(max_deadline, j.d);
    
    // slot[i] 表示时间片 i 是否被占用，初始化为 false
    vector<bool> slot(max_deadline + 1, false);
    int totalProfit = 0;

    for(int i=0; i<n; ++i) {
        // 从截止时间开始向前找空位
        for(int j = min(max_deadline, jobs[i].d); j >= 1; --j) {
            if(!slot[j]) {
                slot[j] = true; // 占用该时间片
                totalProfit += jobs[i].p;
                break;
            }
        }
    }
    return totalProfit;
}
```

#### 3. 硬币找零问题 (Coin Change)

**题目**：面值 25, 10, 5, 1 美分，凑出 3.33 美元 (333美分)，求最少硬币数。

- **贪心策略**：优先使用面值**最大**的硬币。
- **注**：此策略对特定面值体系（如美分）有效，对任意面值未必有效（那就得用动态规划）。
- **复杂度**：$O(K)$，K为硬币种类数。

**代码实现 (C++)**：

C++

```
void solve_coins(int cents) { // 3.33美元 = 333美分
    int coins[] = {25, 10, 5, 1};
    int count = 0;
    for(int val : coins) {
        int num = cents / val; // 能用几个当前最大面值
        count += num;
        cents %= val;          // 剩下的钱
        cout << "面值 " << val << ": " << num << " 个" << endl;
    }
    cout << "总个数: " << count << endl;
}
```

#### 4. 海岸线基站问题 (Interval Covering)

**题目**：点 $p_i(x_i, y_i)$，覆盖半径 $d$，在 x 轴选最少点覆盖所有船。

- **问题转化**：对于每个船 $i$，能在 x 轴上覆盖它的范围是一个区间 $[x_i - \sqrt{d^2-y_i^2}, \ x_i + \sqrt{d^2-y_i^2}]$。问题转化为：**给定 N 个区间，选最少的点使每个区间内至少有一个点**。
- **贪心策略**：
  1. 将所有区间按**右端点**从小到大排序。
  2. 选择第一个区间的右端点作为基站。
  3. 跳过所有包含该基站的区间，找到第一个未被覆盖的区间，选其右端点，重复。
- **复杂度**：$O(N \log N)$。

**代码实现 (C++)**：

C++

```
struct Interval { double l, r; };
bool cmp(Interval a, Interval b) { return a.r < b.r; } // 按右端点排序

int solve_radar(int n, double d, vector<pair<double, double>> points) {
    vector<Interval> segs;
    for(auto& p : points) {
        if(p.second > d) return -1; // 无法覆盖
        double delta = sqrt(d*d - p.second*p.second);
        segs.push_back({p.first - delta, p.first + delta});
    }
    sort(segs.begin(), segs.end(), cmp);

    int count = 0;
    double last_pos = -1e18; // 上一个基站位置

    for(auto& s : segs) {
        if(s.l > last_pos) { // 当前区间未被覆盖
            count++;
            last_pos = s.r; // 贪心：选当前区间的最右端
        }
    }
    return count;
}
```

#### 5. 生产与存储计划 (Production Planning)

**题目**：第 $i$ 月生产成本 $c_i$，存储成本 1/月，需求 $y_i$。求最小总成本及生产计划 $x_i$。

- 贪心策略：对于第 $i$ 个月的需求 $y_i$，我们应该寻找“最便宜的供应源”。

  供应源可以是当月生产（成本 $c_i$），也可以是上个月生产并存储（成本 $c_{i-1} + 1$），甚至是上上个月（$c_{i-2} + 2$）。

  实际上，第 $i$ 月的最优单位成本 $best\_cost_i = \min(c_i, \ best\_cost_{i-1} + 1)$。

- **复杂度**：$O(N)$。

**代码实现 (C++)**：

C++

```
void solve_production(int n, vector<int> c, vector<int> y) {
    vector<int> x(n, 0); // 生产计划
    long long total_cost = 0;
    
    // 记录每个月需求的最佳来源月份
    // pair<成本, 来源月份>
    pair<int, int> best_source = {c[0], 0}; 
    
    // 第1个月肯定自己生产或者由之前月份生产(这里假设从第1个月开始)
    // 实际上我们在遍历时动态维护"当前最便宜的供应价"
    
    for(int i=0; i<n; ++i) {
        // 比较：当月生产 vs 上个月的最优方案+1元存储费
        if (i > 0) {
            // 如果 "延续之前的存储" 比如 "当月生产" 贵
            if (best_source.first + 1 < c[i]) {
                best_source.first += 1; // 成本增加1
                // source月份不变
            } else {
                best_source = {c[i], i}; // 更新为当月生产更划算
            }
        } else {
            best_source = {c[i], 0};
        }
        
        // 累加总成本
        total_cost += (long long)best_source.first * y[i];
        
        // 记录生产计划：需求 y[i] 是由 best_source.second 这个月生产的
        x[best_source.second] += y[i];
    }
    
    cout << "最小总成本: " << total_cost << endl;
    cout << "生产计划 x: ";
    for(int val : x) cout << val << " ";
    cout << endl;
}
```

#### 6. 黑白点连线 (1D Matching)

**题目**：直线 2n 个点，n 黑 n 白，两两配对连线，求最小总长度。

- **贪心策略**：在直线上，使得配对总距离最小的方案是**“顺序匹配”**。即：第 1 个白点连第 1 个黑点，第 2 个白点连第 2 个黑点……第 $k$ 个白点连第 $k$ 个黑点。
  - *直观理解*：避免连线“交叉”。交叉的连线通常比不交叉的更长（三角形两边之和大于第三边）。
- **复杂度**：$O(N \log N)$ (主要是排序)。

**代码实现 (C++)**：

C++

```
int solve_connect(int n, vector<int> whites, vector<int> blacks) {
    // 1. 分别排序
    sort(whites.begin(), whites.end());
    sort(blacks.begin(), blacks.end());
    
    int total_len = 0;
    // 2. 顺序匹配并累加距离
    for(int i=0; i<n; ++i) {
        total_len += abs(whites[i] - blacks[i]);
    }
    return total_len;
}
```
