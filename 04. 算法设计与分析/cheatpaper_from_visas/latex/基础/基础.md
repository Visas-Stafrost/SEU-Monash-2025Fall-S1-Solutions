### 第一部分：递归方程求解方法讲解

#### 1. 逐层展开法 (Iteration Method / Expansion)

适用场景：适用于形式简单、规模逐层递减（如 $T(n-1)$）的递归方程。

核心思想：将递归式一步步展开，直到找到规律，最后求和。

步骤：

1. 写出 $T(n)$ 的表达式。
2. 将 $T(n-1)$（或下一层）代入，得到含 $T(n-2)$ 的式子。
3. 重复此过程，直到第 $k$ 层。
4. 观察通项公式，利用初始条件（如 $T(0)$）确定 $k$ 的值，最后计算级数和。

#### 2. 变量替换法 (Variable Substitution Method)

适用场景：适用于 $T(n)$ 内部包含根号（如 $\sqrt{n}$）或指数形式，无法直接使用 Master 定理的情况。

核心思想：通过换元（如令 $n = 2^m$ 或 $m = \log n$），将复杂的非线性递归转化为我们熟悉的线性递归或 Master 定理形式。

步骤：

1. 设定变换，例如 $m = \log n$ （即 $n = 2^m$）。
2. 将原方程中的 $n$ 替换为 $m$ 的表达式。
3. 定义新函数 $S(m) = T(2^m)$，解出 $S(m)$。
4. 最后反解回 $T(n)$。

#### 3. Master 定理 (Master Theorem)

适用场景：专用于解决分治算法的递归式，形式为 $T(n) = aT(n/b) + f(n)$。

核心思想：通过比较 $f(n)$ 与 $n^{\log_b a}$ 的增长速率来直接写出复杂度。

定理内容：

比较 $n^{\log_b a}$ （临界函数）与 $f(n)$ （非递归代价）：

- **Case 1 (头重脚轻)**：若 $n^{\log_b a}$ 更大（即 $f(n) = O(n^{\log_b a - \epsilon})$），则 $T(n) = \Theta(n^{\log_b a})$。
- **Case 2 (势均力敌)**：若两者同阶（即 $f(n) = \Theta(n^{\log_b a} \log^k n)$），则 $T(n) = \Theta(n^{\log_b a} \log^{k+1} n)$。
- **Case 3 (头轻脚重)**：若 $f(n)$ 更大（即 $f(n) = \Omega(n^{\log_b a + \epsilon})$），且满足正则条件（$af(n/b) \le cf(n)$），则 $T(n) = \Theta(f(n))$。


### 第二部分：习题全解

以下是文件中所有9道题的解答。

#### 1. $T(n)=3T(n-1), T(0)=5$

- **方法**：**逐层展开法**

- **解析**：

  $$  \begin{aligned}  T(n) &= 3T(n-1) \\       &= 3[3T(n-2)] = 3^2T(n-2) \\       &= 3^2[3T(n-3)] = 3^3T(n-3) \\       &\dots \\       &= 3^k T(n-k)  \end{aligned}$$

  当 $n-k=0$ 即 $k=n$ 时到达边界 $T(0)=5$。

  

  $$T(n) = 3^n T(0) = 5 \cdot 3^n$$

- **结果**：$T(n) = 5 \cdot 3^n$

#### 2. $T(n)=5T(n-1)-6T(n-2), T(0)=1, T(1)=4$

- **方法**：**特征方程法**（属于常系数线性齐次递推，虽然题目要求选方法，但这题标准解法如下）

- 解析：

  特征方程为 $r^2 - 5r + 6 = 0$，解得 $(r-2)(r-3)=0$，根为 $r_1=2, r_2=3$。

  通解形式为 $T(n) = c_1 \cdot 2^n + c_2 \cdot 3^n$。

  代入初始条件：

  $$  \begin{cases}  T(0) = c_1 + c_2 = 1 \\  T(1) = 2c_1 + 3c_2 = 4  \end{cases}$$

  解得 $c_1 = -1, c_2 = 2$。

  所以 $T(n) = -1 \cdot 2^n + 2 \cdot 3^n$。

- **结果**：$T(n) = 2 \cdot 3^n - 2^n$

#### 3. $T(n)=nT(n-1)+1, T(0)=1$

- **方法**：**逐层展开 / 转化法**

- 解析：

  两边同时除以 $n!$：

  

  $$\frac{T(n)}{n!} = \frac{T(n-1)}{(n-1)!} + \frac{1}{n!}$$

  

  令 $S(n) = \frac{T(n)}{n!}$，则有 $S(n) = S(n-1) + \frac{1}{n!}$。

  这是一个简单的累加式：

  

  $$S(n) = S(0) + \sum_{k=1}^n \frac{1}{k!} = \frac{T(0)}{0!} + \sum_{k=1}^n \frac{1}{k!} = 1 + \sum_{k=1}^n \frac{1}{k!} = \sum_{k=0}^n \frac{1}{k!}$$

  

  所以 $T(n) = n! S(n) = n! \sum_{k=0}^n \frac{1}{k!}$。

  （注：$\sum_{k=0}^n \frac{1}{k!} \approx e$，所以 $T(n) \approx \lfloor e \cdot n! \rfloor$）

- **结果**：$T(n) = n! \sum_{k=0}^n \frac{1}{k!}$

#### 4. $T(n)=\sqrt{n}T(\sqrt{n})+n$

- **方法**：**变量替换法**

- 解析：

  两边除以 $n$：

  

  $$\frac{T(n)}{n} = \frac{T(\sqrt{n})}{\sqrt{n}} + 1$$

  

  令 $n = 2^k$（即 $k = \log n$），设 $S(k) = \frac{T(2^k)}{2^k}$。

  注意到 $\sqrt{n} = 2^{k/2}$，方程变为：

  

  $$S(k) = S(k/2) + 1$$

  

  这符合 Master 定理 Case 2（$a=1, b=2, f(k)=1$），$S(k) = \Theta(\log k)$。

  代回 $n$：

  

  $$\frac{T(n)}{n} = \Theta(\log(\log n))$$

- **结果**：$T(n) = \Theta(n \log \log n)$

#### 5. $T(n)=5T(\frac{n}{3})+n, T(1)=1$

- **方法**：**Master 定理**

- 解析：

  $a=5, b=3, f(n)=n$。

  计算临界指数 $\log_b a = \log_3 5 \approx 1.46$。

  因为 $f(n) = n^1 = O(n^{1.46})$，且 $1 < 1.46$，这属于 Case 1（递归部分主导）。

- **结果**：$T(n) = \Theta(n^{\log_3 5})$

#### 6. $T(n) = 2T(\frac{n}{2}) + n^2, T(1)=1$

*(注：题目中 $T()$ 括号为空，根据算法题惯例推断为 $n/2$)*

- **方法**：**Master 定理**

- 解析：

  $a=2, b=2, f(n)=n^2$。

  计算临界指数 $\log_b a = \log_2 2 = 1$。

  因为 $f(n) = n^2 = \Omega(n^{1+\epsilon})$，且满足正则条件 $2(n/2)^2 = n^2/2 < n^2$，这属于 Case 3（非递归部分主导）。

- **结果**：$T(n) = \Theta(n^2)$

#### 7. $T(n)=7T(\frac{n}{7})+n$

- **方法**：**Master 定理**

- 解析：

  $a=7, b=7, f(n)=n$。

  计算临界指数 $\log_b a = \log_7 7 = 1$。

  因为 $f(n) = n^1$，与 $n^{\log_b a}$ 同阶，这属于 Case 2。

- **结果**：$T(n) = \Theta(n \log n)$

#### 8. $T(n)=8T(\frac{n}{6})+n^{\frac{3}{2}}\log n$

- **方法**：**Master 定理**

- 解析：

  $a=8, b=6, f(n)=n^{1.5}\log n$。

  计算临界指数 $\log_6 8 \approx 1.16$。

  比较 $f(n)$ 指数 $1.5$ 与 $\log_6 8 \approx 1.16$。显然 $1.5 > 1.16$，属于 Case 3（非递归部分主导）。

  验证正则条件：$8(\frac{n}{6})^{1.5}\log(\frac{n}{6}) \approx \frac{8}{14.7} n^{1.5} \dots \le c n^{1.5} \log n$，成立（因 $8/14.7 < 1$）。

- **结果**：$T(n) = \Theta(n^{\frac{3}{2}} \log n)$

#### 9. $T(n)=2T(n^{\frac{1}{3}})+1$

- **方法**：**变量替换法 + Master 定理**

- 解析：

  令 $n = 3^m$（以便开立方 $n^{1/3} = 3^{m/3}$），设 $S(m) = T(3^m)$。

  方程变为：$S(m) = 2S(m/3) + 1$。

  对 $S(m)$ 使用 Master 定理：$a=2, b=3, f(m)=1$。

  $\log_3 2 \approx 0.63$，因为 $f(m)=m^0=1 < m^{0.63}$，属于 Case 1。

  所以 $S(m) = \Theta(m^{\log_3 2})$。

  代回 $n$：$m = \log_3 n$。

  $T(n) = \Theta((\log_3 n)^{\log_3 2}) = \Theta((\log n)^{\log_3 2})$。

- **结果**：$T(n) = \Theta((\log n)^{\log_3 2})$
