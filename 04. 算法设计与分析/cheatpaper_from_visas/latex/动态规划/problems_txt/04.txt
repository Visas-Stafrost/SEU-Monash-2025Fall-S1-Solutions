动态规划章节复习辅导：从核心知识点到解题思路
动态规划章节复习辅导
第一部分：章节核心知识点+解题思路梳理
一、章节核心知识点（含考试重点）
1. 动态规划（DP）核心概念与原理
定义：一种将复杂问题分解为若干个相互关联的子问题，通过求解子问题的最优解并存储复用，最终得到原问题最优解的算法思想。
与分治法的区别：
核心条件（考试高频考点）：
最优子结构：原问题的最优解必然包含子问题的最优解（如矩阵连乘中，整体最优括号化包含子区间的最优括号化）。
重叠子问题：求解过程中，多个子问题会被重复计算（如钢条切割中，r(n)依赖r(n-1)、r(n-2)，而r(n-1)又依赖r(n-2)）。
适用场景：多阶段决策问题（如调度、背包、序列匹配）、求最优值问题（最大收益、最小代价、最长/最短序列）。
2. 典型问题核心知识点
二、动态规划通用解题思路（步骤模板，考试直接套用）
通用5步模板（所有DP问题均可适配）
定义状态：明确dp数组的含义（核心！需覆盖“子问题范围”和“约束条件”）：
一维DP：dp[i] → 前i个元素/长度为i的子问题的最优解（如钢条切割r[n]）。
二维DP：dp[i][j] → 前i个元素+前j个元素/区间[i,j]的子问题的最优解（如LCS的dp[i][j]、矩阵连乘的m[i][j]）。
三维DP：dp[i][j][k] → 增加额外约束（如POJ1458的“前i个数字+k个乘号”）。
推导转移方程：根据子问题关系，分情况讨论dp[i][j]的计算方式：
选择类（如0/1背包）：dp[i][j] = max(选第i个物品的价值, 不选第i个物品的价值)。
切分类（如矩阵连乘）：dp[i][j] = min(所有切分点k对应的子问题代价之和+额外代价)。
匹配类（如LCS）：dp[i][j] = （元素相等时）子问题+1 / （元素不等时）max两个子问题。
初始化边界条件：确定无需计算的基础子问题值（避免递归/循环异常）：
如矩阵连乘：m[i][i] = 0（单个矩阵无需乘法）。
如LCS：dp[0][j] = 0、dp[i][0] = 0（空序列的LCS长度为0）。
如0/1背包：dp[0][j] = 0（无物品时价值为0）。
确定计算顺序：按“子问题规模从小到大”计算（自底向上，避免重复）：
一维DP：从i=1到n（如钢条切割r[1]→r[n]）。
二维DP：先按子问题长度x遍历（如矩阵连乘x从1到n-1），再遍历起始位置i，计算j=i+x。
输出结果+构造最优解（可选）：
直接输出最终状态值（如m[1][n]、dp[1][C]）。
构造解：通过额外数组记录决策过程（如矩阵连乘的s[i][j]记录切分点，LCS的b[i][j]记录转移方向）。
三、高频考点典型例题（贴合考试难度，附详细讲解）
例题1：钢条切割问题（1维DP，考试基础题）
题目：给定长度为5的钢条，价格表p[1]=1、p[2]=5、p[3]=8、p[4]=9、p[5]=10，求切割后的最大收益。
思路分析：适配通用5步模板：
状态定义：r[i] = 长度为i的钢条的最大收益。
转移方程：r[i] = max(p[k] + r[i-k])（k=1~i，切下长度k的钢条，剩余i-k长度取最大收益）。
初始化：r[0] = 0（长度为0无收益）。
计算顺序：r[1]→r[2]→r[3]→r[4]→r[5]。
输出r[5]。
步骤推导：
r[1] = p[1] + r[0] = 1+0=1。
r[2] = max(p[1]+r[1]=2, p[2]+r[0]=5) → 5。
r[3] = max(p[1]+r[2]=6, p[2]+r[1]=6, p[3]+r[0]=8) →8。
r[4] = max(p[1]+r[3]=9, p[2]+r[2]=10, p[3]+r[1]=9, p[4]+r[0]=9) →10。
r[5] = max(p[1]+r[4]=11, p[2]+r[3]=13, p[3]+r[2]=13, p[4]+r[1]=10, p[5]+r[0]=10) →13。
代码框架：
核心思想：通过遍历所有可能的切割方式，复用子问题的最大收益，避免重复计算。
例题2：最长公共子序列（LCS，二维DP，考试高频题）
题目：给定序列X="ABCBDAB"（长度7）、Y="BDCAB"（长度5），求其最长公共子序列的长度及具体序列。
思路分析：
状态定义：dp[i][j] = 序列X前i个元素（X[1..i]）与序列Y前j个元素（Y[1..j]）的LCS长度。
转移方程：
若X[i] == Y[j] → dp[i][j] = dp[i-1][j-1] + 1（当前元素加入LCS）。
若X[i] != Y[j] → dp[i][j] = max(dp[i-1][j], dp[i][j-1])（取子问题最优解）。
初始化：dp[0][j] = 0（j=0..5），dp[i][0] = 0（i=0..7）。
计算顺序：i从1到7，j从1到5。
输出dp[7][5]，并通过记录转移方向b[i][j]回溯LCS。
步骤推导（关键部分表格）：
最终dp[7][5] = 4，回溯得到LCS为"BCAB"或"BDAB"。
代码框架：
核心思想：通过二维表格记录子问题的LCS长度，利用转移方向回溯得到具体序列，体现“最优子结构”。
例题3：0/1背包问题（二维DP，考试重点题）
题目：有3个物品，重量分别为w=[2,3,4]，价值分别为v=[3,4,5]，背包容量C=5，求不超过容量时的最大价值。
思路分析：
状态定义：dp[i][j] = 前i个物品（物品1~i）放入容量为j的背包的最大价值。
转移方程：
若j < w[i-1]（当前物品重量超容量）→ dp[i][j] = dp[i-1][j]（不选当前物品）。
若j >= w[i-1] → dp[i][j] = max(dp[i-1][j], dp[i-1][j - w[i-1]] + v[i-1])（选或不选的最大值）。
初始化：dp[0][j] = 0（j=0~5），dp[i][0] = 0（i=0~3）。
计算顺序：i从1到3，j从1到5。
输出dp[3][5]。
步骤推导（表格）：
最终最大价值为7（选择物品1和物品2）。
代码框架：
核心思想：通过二维表格记录“选或不选”的决策结果，复用子问题的最大价值，体现0/1选择的无后效性。
第二部分：PPT大题逐题详解——矩阵连乘问题
一、题目重现
给定n个矩阵M₁, M₂, ..., Mₙ，其中Mᵢ的维数为rᵢ₋₁×rᵢ（i=1~n）。矩阵乘法满足结合律，不同的括号化方式会导致乘法运算次数不同。例如：3个矩阵M₁(10×100)、M₂(100×5)、M₃(5×50)，按(M₁M₂)M₃计算需10×100×5 + 10×5×50 = 7500次乘法，按M₁(M₂M₃)计算需100×5×50 + 10×100×50 = 75000次乘法。要求找到最优括号化方案，使n个矩阵连乘的乘法运算次数最少。
二、考点定位
动态规划法-矩阵连乘问题（核心考查：最优子结构、重叠子问题、区间DP的实现）。
三、解题思路拆解
适配动态规划通用模板：
状态定义：m[i][j]表示矩阵Mᵢ到Mⱼ（i≤j）连乘的最小乘法次数（子问题：区间[i,j]的最优解）。
转移方程：对于切分点k（i≤k<j），m[i][j] = min(m[i][k] + m[k+1][j] + rᵢ₋₁×rₖ×rⱼ)（子问题最优解之和+当前切分的额外乘法次数）；当i=j时，m[i][j] = 0（单个矩阵无乘法）。
初始化：m[i][i] = 0（i=1~n）。
计算顺序：按子问题长度x（x=j-i+1）从小到大计算，x从1（i=j）到n（i=1,j=n），具体为x从1到n-1，i从1到n-x，j=i+x。
输出结果：m[1][n]（整个区间[1,n]的最优解）。
关键逻辑：通过遍历所有可能的切分点k，找到使子问题代价之和最小的方案，利用区间DP的顺序避免重复计算重叠子问题。
四、详细步骤推导（以n=3，r=[10,100,5,50]为例）
初始化：m[1][1] = 0，m[2][2] = 0，m[3][3] = 0。
计算长度x=2的子问题（i=1,j=2；i=2,j=3）：
x=2时，j=i+1：
m[1][2] = m[1][1] + m[2][2] + r₀×r₁×r₂ = 0 + 0 + 10×100×5 = 5000。
m[2][3] = m[2][2] + m[3][3] + r₁×r₂×r₃ = 0 + 0 + 100×5×50 = 25000。
计算长度x=3的子问题（i=1,j=3）：
切分点k可取值1或2：
k=1：m[1][1] + m[2][3] + r₀×r₁×r₃ = 0 + 25000 + 10×100×50 = 75000。
k=2：m[1][2] + m[3][3] + r₀×r₂×r₃ = 5000 + 0 + 10×5×50 = 7500。
取最小值：m[1][3] = min(75000, 7500) = 7500。
最终结果：m[1][3] = 7500，对应最优括号化方案(M₁M₂)M₃。

六、改编思路拓展
改编方向1：增加矩阵权重
题目修改：每个矩阵有一个权重wᵢ，乘法次数需叠加权重（如总代价=乘法次数×Σwᵢ），求最小总代价。
解题调整：转移方程改为m[i][j] = min(m[i][k] + m[k+1][j] + r[i-1]×r[k]×r[j] × sum(w[i..j]))，其中sum(w[i..j])为区间[i,j]矩阵的权重和（需额外维护前缀和数组）。
改编方向2：求最优括号化方案的具体步骤
题目修改：不仅要求最小乘法次数，还需输出每个矩阵的乘法顺序（如“先乘M1和M2，再乘结果与M3”）。
解题调整：利用s[i][j]数组回溯切分点，递归输出每个区间的括号化方式，如上述print_optimal_parens函数的扩展。
改编方向3：高维矩阵连乘
题目修改：矩阵为3维（如Mᵢ是a×b×c的张量），张量乘法的代价公式不同，求最小代价。
解题调整：修改转移方程中的代价计算部分（适配张量乘法的代价公式），状态定义和计算顺序不变。
第三部分：PPT大题逐题详解——钢条切割问题
一、题目重现
给定一段长度为n英寸的钢条和价格表pᵢ（i=1~n，pᵢ为长度i的钢条的售价），钢条可切割为任意段（也可不切割），求切割后各段钢条的总收益最大。例如：长度为4的钢条，价格表p[1]=1、p[2]=5、p[3]=8、p[4]=9，最优切割方案为切成2段长度2的钢条，总收益5+5=10。
二、考点定位
动态规划法-钢条切割问题（核心考查：1维DP、重叠子问题的优化、自底向上与备忘录方法的实现）。
三、解题思路拆解
适配动态规划通用模板：
状态定义：r[n]表示长度为n的钢条的最大收益（子问题：长度为n的最优解）。
转移方程：r[n] = max(p[i] + r[n-i])（i=1~n，切下长度i的钢条，剩余长度n-i取最大收益）；r[0] = 0（长度为0无收益）。
初始化：r[0] = 0。
计算顺序：从长度1到n，依次计算r[1]、r[2]、...、r[n]（子问题规模从小到大）。
输出结果：r[n]。
关键逻辑：通过遍历所有可能的切割长度i，复用子问题r[n-i]的结果，避免重复计算（如r[4]依赖r[3]、r[2]，而r[3]又依赖r[2]、r[1]）。
四、详细步骤推导（以n=4，p=[1,5,8,9]为例）
初始化：r[0] = 0。
计算r[1]：
仅有一种选择：不切割，收益p[1] + r[0] = 1+0=1 → r[1] = 1。
计算r[2]：
选项1：切为1+1 → 收益p[1]+r[1] = 1+1=2。
选项2：不切割 → 收益p[2]+r[0] =5+0=5。
取最大值 → r[2] =5。
计算r[3]：
选项1：切为1+2 → 收益p[1]+r[2] =1+5=6。
选项2：切为2+1 → 收益p[2]+r[1] =5+1=6。
选项3：不切割 → 收益p[3]+r[0] =8+0=8。
取最大值 → r[3] =8。
计算r[4]：
选项1：切为1+3 → 收益p[1]+r[3] =1+8=9。
选项2：切为2+2 → 收益p[2]+r[2] =5+5=10。
选项3：切为3+1 → 收益p[3]+r[1] =8+1=9。
选项4：不切割 → 收益p[4]+r[0] =9+0=9。
取最大值 → r[4] =10。

六、改编思路拓展
改编方向1：带切割成本
题目修改：每次切割需支付固定成本c（如每次切割花费1），求最大净收益（总收益-切割次数×c）。
解题调整：转移方程改为r[n] = max(p[i] + r[n-i] - (1 if n-i >0 else 0)*c)（切割后剩余长度>0则需支付成本），初始化r[0]=0不变。
改编方向2：限制切割次数
题目修改：最多允许切割k次（如k=1，即最多分成2段），求最大收益。
解题调整：状态定义改为二维dp[k][n]表示切割k次、长度n的最大收益，转移方程dp[k][n] = max(p[i] + dp[k-1][n-i])（i=1~n），初始化dp[0][n] = p[n]（不切割）。
改编方向3：价格表动态变化
题目修改：价格表p[i]与切割段数相关（如切割段数越多，每段价格上浮10%），求最大收益。
解题调整：状态定义增加段数维度dp[m][n]表示分成m段、长度n的最大收益，转移方程dp[m][n] = max(dp[m-1][n-i] + p[i]×1.1^(m-1))，遍历m从1到n（最多n段）。
第四部分：PPT大题逐题详解——最长公共子序列（LCS）问题
一、题目重现
给定两个序列X=(x₁,x₂,...,xₘ)和Y=(y₁,y₂,...,yₙ)，子序列定义为“从序列中选取若干元素，保持原有顺序但不要求连续”。公共子序列是同时属于X和Y的子序列，最长公共子序列（LCS）是长度最大的公共子序列。例如：X=(A,B,C,B,D,A,B)，Y=(B,D,C,A,B)，其LCS长度为4，具体序列如(B,C,A,B)。要求给定X和Y，求其LCS的长度及具体序列。
二、考点定位
动态规划法-最长公共子序列问题（核心考查：二维DP、最优子结构的分情况讨论、LCS的回溯构造）。
三、解题思路拆解
适配动态规划通用模板：
状态定义：dp[i][j]表示X的前i个元素（X[1..i]）与Y的前j个元素（Y[1..j]）的LCS长度（子问题：两个前缀的最优解）。
转移方程：
若X[i] == Y[j] → dp[i][j] = dp[i-1][j-1] + 1（当前元素加入LCS，子问题为X[1..i-1]与Y[1..j-1]）。
若X[i] != Y[j] → dp[i][j] = max(dp[i-1][j], dp[i][j-1])（子问题为“X[1..i-1]与Y[1..j]”或“X[1..i]与Y[1..j-1]”的最优解）。
初始化：dp[0][j] = 0（j=0~n），dp[i][0] = 0（i=0~m）（空序列的LCS长度为0）。
计算顺序：i从1到m，j从1到n（按行或按列遍历均可）。
输出结果：dp[m][n]（完整序列的LCS长度），通过转移方向数组回溯具体序列。
关键逻辑：利用“元素相等则延伸LCS，元素不等则取子问题最优”的规则，覆盖所有可能的子问题，二维表格存储结果避免重复计算。
四、详细步骤推导（以X=(A,B,C,B,D,A,B)，Y=(B,D,C,A,B)为例）
序列索引说明：X[1]=A, X[2]=B, X[3]=C, X[4]=B, X[5]=D, X[6]=A, X[7]=B；Y[1]=B, Y[2]=D, Y[3]=C, Y[4]=A, Y[5]=B。
初始化：dp[0][j] = 0（j=0~5），dp[i][0] = 0（i=0~7）。
逐行逐列计算dp[i][j]：
i=1（X[1]=A）：
j=1（Y[1]=B）：A≠B → dp[1][1] = max(dp[0][1], dp[1][0]) = 0。
j=2（Y[2]=D）：A≠D → dp[1][2] = 0。
j=3（Y[3]=C）：A≠C → dp[1][3] = 0。
j=4（Y[4]=A）：A=A → dp[1][4] = dp[0][3] +1 =1。
j=5（Y[5]=B）：A≠B → dp[1][5] = max(dp[0][5], dp[1][4])=1。
i=2（X[2]=B）：
j=1（Y[1]=B）：B=B → dp[2][1] = dp[1][0]+1=1。
j=2（Y[2]=D）：B≠D → max(dp[1][2], dp[2][1])=1。
j=3（Y[3]=C）：B≠C → max(dp[1][3], dp[2][2])=1。
j=4（Y[4]=A）：B≠A → max(dp[1][4], dp[2][3])=1。
j=5（Y[5]=B）：B=B → dp[2][5] = dp[1][4]+1=2。
后续i=3~7依次计算，最终dp[7][5] =4。
回溯构造LCS：
从i=7,j=5开始：X[7]=B == Y[5]=B → 加入LCS，i=6,j=4。
i=6,j=4：X[6]=A == Y[4]=A → 加入LCS，i=5,j=3。
i=5,j=3：X[5]=D != Y[3]=C → dp[5][3] = dp[4][3]（X[4]=B）→ i=4,j=3。
i=4,j=3：X[4]=B != Y[3]=C → dp[4][3] = dp[3][3]（X[3]=C）→ i=3,j=3。
i=3,j=3：X[3]=C == Y[3]=C → 加入LCS，i=2,j=2。
i=2,j=2：X[2]=B != Y[2]=D → dp[2][2] = dp[2][1]（Y[1]=B）→ i=2,j=1。
i=2,j=1：X[2]=B == Y[1]=B → 加入LCS，i=1,j=0（终止）。
反转回溯结果：B→C→A→B → LCS为"BCAB"。
五、答案呈现

def LCS(X, Y):
    m, n = len(X), len(Y)
    dp = [[0]*(n+1) for _ in range(m+1)]
    b = [[0]*(n+1) for _ in range(m+1)]  # 记录转移方向：1=↖,2=↑,3=←
    for i in range(1, m+1):
        for j in range(1, n+1):
            if X[i-1] == Y[j-1]:
                dp[i][j] = dp[i-1][j-1] + 1
                b[i][j] = 1
            elif dp[i-1][j] >= dp[i][j-1]:
                dp[i][j] = dp[i-1][j]
                b[i][j] = 2
            else:
                dp[i][j] = dp[i][j-1]
                b[i][j] = 3
    # 回溯构造LCS
    def backtrack(i, j):
        if i == 0 or j == 0:
            return ""
        if b[i][j] == 1:
            return backtrack(i-1, j-1) + X[i-1]
        elif b[i][j] == 2:
            return backtrack(i-1, j)
        else:
            return backtrack(i, j-1)
    return dp[m][n], backtrack(m, n)

def zero_one_knapsack(w, v, C):
    n = len(w)
    dp = [[0]*(C+1) for _ in range(n+1)]
    for i in range(1, n+1):
        for j in range(1, C+1):
            if j < w[i-1]:
                dp[i][j] = dp[i-1][j]
            else:
                dp[i][j] = max(dp[i-1][j], dp[i-1][j - w[i-1]] + v[i-1])
    # 构造最优解（可选）
    x = [0]*n
    j = C
    for i in range(n, 0, -1):
        if dp[i][j] != dp[i-1][j]:
            x[i-1] = 1
            j -= w[i-1]
    return dp[n][C], x

def matrix_chain_order(r):
    n = len(r) - 1  # 矩阵个数为r的长度-1
    m = [[0]*(n+1) for _ in range(n+1)]  # m[i][j]存储区间[i,j]的最小次数
    s = [[0]*(n+1) for _ in range(n+1)]  # s[i][j]存储区间[i,j]的最优切分点k
    for x in range(1, n):  # x为子问题长度-1（x=1对应长度2）
        for i in range(1, n - x + 1):
            j = i + x
            m[i][j] = float('inf')
            for k in range(i, j):
                q = m[i][k] + m[k+1][j] + r[i-1] * r[k] * r[j]
                if q < m[i][j]:
                    m[i][j] = q
                    s[i][j] = k
    return m, s

def cut_rod_memoized(p, n):

        if r[length] != -1:

            max_val = max(max_val, p[i-1] + dp(length - i))

                b[i][j] = 1
            elif dp[i-1][j] >= dp[i][j-1]:
                dp[i][j] = dp[i-1][j]
                b[i][j] = 2
            else:
                dp[i][j] = dp[i][j-1]
                b[i][j] = 3
    
    # 回溯构造LCS
    def backtrack(i, j):
        if i == 0 or j == 0:
            return []
        if b[i][j] == 1:
            # 元素相等，加入LCS，回溯左上角
            return backtrack(i-1, j-1) + [X[i-1]]
        elif b[i][j] == 2:
            # 回溯上方
            return backtrack(i-1, j)
        else:
            # 回溯左方
            return backtrack(i, j-1)
    
    lcs_length = dp[m][n]
    lcs_sequence = backtrack(m, n)
    return lcs_length, ''.join(lcs_sequence)

def optimal_bst(p, q, n):
    # c[i][j]：区间[i,j]的最优平均搜索长度
    c = [[0]*(n+1) for _ in range(n+1)]
    # w[i][j]：区间[i,j]的总权值
    w = [[0]*(n+1) for _ in range(n+1)]
    # root[i][j]：区间[i,j]的最优根节点
    root = [[0]*(n+1) for _ in range(n+1)]
    
    # 初始化：i=j时
    for i in range(n+1):
        c[i][i] = 0
        w[i][i] = q[i]
    
    # 按子问题长度x遍历（x=j-i）
    for x in range(1, n+1):
        for i in range(n - x + 1):
            j = i + x
            c[i][j] = float('inf')
            w[i][j] = w[i][j-1] + p[j-1] + q[j]  # p是0索引（p[0]对应k1）
            # 遍历所有可能的根节点k（i<k<=j）
            for k in range(i+1, j+1):
                # 计算当前根节点k的代价
                cost = w[i][j]
                if k-1 > i:
                    cost += c[i][k-1]
                if k < j:
                    cost += c[k][j]
                # 更新最优解
                if cost < c[i][j]:
                    c[i][j] = cost
                    root[i][j] = k
    return c, root, c[0][n]

def flow_shop_scheduling(a, b):
    n = len(a)
    # 按Johnson不等式分组排序
    group_a = []  # a[i] < b[i]，按a升序
    group_b = []  # a[i] >= b[i]，按b降序
    for i in range(n):
        if a[i] < b[i]:
            group_a.append( (a[i], b[i], i+1) )  # 存储a,b,作业编号
        else:
            group_b.append( (a[i], b[i], i+1) )
    # 排序
    group_a.sort(key=lambda x: x[0])  # A组按a升序
    group_b.sort(key=lambda x: -x[1])  # B组按b降序
    # 最优顺序
    optimal_order = [job[2] for job in group_a + group_b]
    # 计算总加工时间
    m1_time = 0  # M1的当前结束时间
    m2_time = 0  # M2的当前结束时间
    for job in group_a + group_b:
        ai, bi = job[0], job[1]
        m1_time += ai
        # M2开始时间取M1结束时间和M2当前时间的最大值
        m2_start = max(m1_time, m2_time)
        m2_time = m2_start + bi
    return optimal_order, m2_time
