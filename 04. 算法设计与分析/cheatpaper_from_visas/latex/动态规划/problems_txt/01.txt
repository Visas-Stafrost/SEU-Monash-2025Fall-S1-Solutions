0/1 背包问题：深度解析与解题步骤
第七部分：PPT大题逐题详解——0/1背包问题
一、题目重现
给定n个物品和一个容量为C的背包，物品i的重量为wᵢ（wᵢ>0），价值为vᵢ（vᵢ>0）。每个物品只能选择“装入”或“不装入”背包（即0/1选择，不可分割），要求在背包总重量不超过容量C的前提下，使装入背包的物品总价值最大。形式化描述如下：
输入：C>0，w=[w₁,w₂,...,wₙ]，v=[v₁,v₂,...,vₙ]
输出：二进制向量(x₁,x₂,...,xₙ)（xᵢ∈{0,1}），满足Σwᵢxᵢ≤C，且Σvᵢxᵢ最大。
例如：n=3，w=[2,3,4]，v=[3,4,5]，C=5，最优解为装入物品1（w=2,v=3）和物品2（w=3,v=4），总重量5，总价值7。
二、考点定位
动态规划法-0/1背包问题（核心考查：二维DP状态定义、0-1选择的转移逻辑、最优解构造、空间优化思路）。
三、解题思路拆解
适配动态规划通用模板：
状态定义：dp[i][j]表示“前i个物品（物品1~i）放入容量为j的背包”的最大价值（子问题：限定物品范围和背包容量的最优解）。
转移方程：
若j < wᵢ（当前物品重量超过背包容量，无法装入）→ dp[i][j] = dp[i-1][j]（继承前i-1个物品的最优解）。
若j ≥ wᵢ（可选择装入或不装入）→ dp[i][j] = max(dp[i-1][j]（不装入）, dp[i-1][j - wᵢ] + vᵢ（装入，加上当前物品价值）)。
初始化：
dp[0][j] = 0（j=0~C）：无物品时，无论容量多大，价值均为0。
dp[i][0] = 0（i=0~n）：背包容量为0时，无法装入任何物品，价值为0。
计算顺序：i从1到n（遍历物品），j从1到C（遍历容量），按行优先或列优先均可。
输出结果：dp[n][C]（所有物品、满容量的最大价值），通过回溯dp数组构造具体装入方案。
关键逻辑：通过“装或不装”的二元选择覆盖所有可能情况，利用二维表格存储子问题结果，避免重复计算；核心是“状态转移时仅依赖前一行的子问题结果”，为空间优化（滚动数组）提供基础。

六、改编思路拓展
改编方向1：多重背包问题
题目修改：每个物品的数量不限（或有限定数量kᵢ），可多次装入背包，求最大价值。
解题调整：
无限多重背包：正序遍历容量（dp[j] = max(dp[j], dp[j - wi] + vi)），允许重复使用物品。
有限多重背包：将物品拆分为“二进制表示的多个0/1物品”（如数量5拆为1+2+2），转化为0/1背包求解。
改编方向2：带双重约束的背包
题目修改：背包不仅有重量限制C，还有体积限制V，每个物品有体积sᵢ，求不超重量和体积的最大价值。
解题调整：状态定义改为三维dp[i][j][k]（前i个物品，重量j，体积k的最大价值），转移方程增加体积约束：dp[i][j][k] = max(dp[i-1][j][k], dp[i-1][j-wi][k-si] + vi)（j≥wi且k≥si）。
改编方向3：价值上限的最小重量
题目修改：给定价值上限V，求装入物品总价值≥V时的最小重量（反向优化目标）。
解题调整：状态定义改为dp[j]表示“价值≥j的最小重量”，初始化dp[0]=0，dp[j]=∞（j>0），转移方程：dp[j] = min(dp[j], dp[max(0, j-vi)] + wi)。
第八部分：PPT大题逐题详解——POJ1458 数字加减乘号最大结果问题
一、题目重现
给定N个1-9的数字（v₁,v₂,...,vₙ），不改变数字的相对位置，在相邻数字间加入K个乘号和（N-K-1）个加号（每个相邻位置必加一个符号），括号可任意添加，使最终结果最大。要求：
说明问题的最优子结构性质和子问题重叠性质；
设计动态规划算法求解。
例如：N=5，K=2，数字为1、2、3、4、5，可能的方案：
1×2×(3+4+5)=24
1×(2+3)×(4+5)=45
(1×2+3)×(4+5)=45
最优结果为45。
二、考点定位
动态规划法-区间DP+运算符组合优化（核心考查：三维DP状态定义、乘号分配的转移逻辑、最优子结构与重叠子问题分析）。
三、解题思路拆解
1. 问题性质分析（考试必答）
最优子结构：若前i个数字用k个乘号的最大结果为dp[i][k]，则对于任意j < i，前j个数字用k-1个乘号的最大结果dp[j][k-1]与第j+1到i个数字的和（或乘积，因括号可调整，连续加号等价于和）的乘积，构成dp[i][k]的候选值。即dp[i][k] = max(dp[j][k-1] × sum(v[j+1..i]))（j从k到i-1，保证前j个数字能分配k-1个乘号）。
子问题重叠：计算dp[i][k]时，需多次用到dp[j][k-1]（不同i可能共享同一j和k-1），且sum(v[j+1..i])可通过前缀和数组预处理，避免重复计算。
2. 动态规划通用模板适配
状态定义：
dp[i][k]：表示“前i个数字（v₁~vᵢ）加入k个乘号”的最大结果（子问题：限定数字个数和乘号数的最优解）。
辅助数组sum_prefix[i]：前缀和数组，sum_prefix[i] = v₁ + v₂ + ... + vᵢ，sum(v[j+1..i]) = sum_prefix[i] - sum_prefix[j]（连续加号的结果等价于和，因加法满足结合律，括号不影响结果）。
转移方程：
当k=0（无乘号，全为加号）→ dp[i][0] = sum_prefix[i]（直接求和）。
当k≥1（有乘号）→ dp[i][k] = max{ dp[j][k-1] × (sum_prefix[i] - sum_prefix[j]) | k ≤ j < i }（前j个数字用k-1个乘号，第j+1到i个数字用加号求和，两者相乘；j≥k保证前j个数字能分配k-1个乘号）。
初始化：
sum_prefix[0] = 0，sum_prefix[i] = sum_prefix[i-1] + v[i-1]（v为0索引数组）。
dp[i][0] = sum_prefix[i]（i=1~N）。
dp[i][k] = 0（k > i-1，因i个数字最多有i-1个符号，乘号数不能超过i-1）。
计算顺序：
先预处理前缀和数组。
按乘号数k从1到K遍历（k是外层循环，保证计算dp[i][k]时dp[j][k-1]已计算）。
按数字个数i从k+1到N遍历（i需大于k，因k个乘号至少需要k+1个数字）。
按切分点j从k到i-1遍历（j需≥k，保证前j个数字能分配k-1个乘号）。
输出结果：dp[N][K]（前N个数字用K个乘号的最大结果）。

五、答案呈现
1. 算法代码框架（含前缀和预处理）
2. 问题性质说明（考试答题模板）
最优子结构性质：对于前i个数字用k个乘号的最优结果dp[i][k]，必然存在某个切分点j（k≤j<i），使得前j个数字用k-1个乘号的结果dp[j][k-1]与第j+1到i个数字的和的乘积为最优。若dp[j][k-1]不是前j个数字用k-1个乘号的最优解，则存在更优的dp’[j][k-1]，替换后可得到比dp[i][k]更优的结果，与dp[i][k]是最优解矛盾，故最优子结构成立。
子问题重叠性质：计算不同的dp[i][k]时，会重复用到相同的dp[j][k-1]。例如，计算dp[5][2]时用到dp[3][1]，计算dp[4][2]时也用到dp[3][1]，无需重复计算，可通过DP表格存储复用，体现重叠子问题。
六、改编思路拓展

解题调整：状态定义改为dp[i][k][m]（前i个数字用k个乘号、m个除号的最大结果），转移方程需考虑切分点后是乘、除或加，且除法需保证除数非零，需同时维护最大和最小值（因负数除法可能得到更大结果）。
改编方向2：数字含负数
题目修改：数字可为负数（-9~9），其余条件不变，求最大结果。
解题调整：转移方程需同时维护最大和最小值（因负数×负数=正数，可能得到更大结果），状态定义改为dp_max[i][k]和dp_min[i][k]，转移时考虑两种情况的乘积。
改编方向3：限制括号层数

第九部分：PPT大题逐题详解——序列划分最小化最大值和问题
一、题目重现
给定长度为N的整数序列(a₁,a₂,...,aₙ)，将其划分为若干个连续的子序列（子序列是连续段），满足每个子序列中整数的和不大于B。设计一种划分方法，使所有子序列中“最大值”的和最小。要求：
说明问题的最优子结构性质和子问题重叠性质；
设计动态规划算法求解。
例如：序列(2,2,2,8,1,8,2,1)，B=17，最优划分为(2,2,2)（和=6，最大值=2）、(8,1,8)（和=17，最大值=8）、(2,1)（和=3，最大值=2），最大值和为2+8+2=12。
二、考点定位
动态规划法-划分型DP（核心考查：一维DP状态定义、连续子序列约束的转移逻辑、最优子结构分析）。
三、解题思路拆解
1. 问题性质分析（考试必答）
最优子结构：设dp[i]表示“前i个元素（a₁~aᵢ）的最小化最大值和”，则对于任意j < i，若子序列aⱼ₊₁~aᵢ的和≤B，则dp[i] = min(dp[j] + max(aⱼ₊₁~aᵢ))（前j个元素的最优解+当前子序列的最大值）。若dp[i]是最优解，则dp[j]必是前j个元素的最优解（否则替换为更优的dp’[j]，可得到比dp[i]更优的结果，矛盾），故最优子结构成立。
子问题重叠：计算dp[i]时，需多次用到dp[j]（不同i可能共享同一j），且max(aⱼ₊₁aᵢ)、sum(aⱼ₊₁aᵢ)可通过预处理或动态计算复用，体现子问题重叠。
2. 动态规划通用模板适配
状态定义：dp[i]表示“前i个元素（a₁~aᵢ）按要求划分后的最小最大值和”（子问题：限定前i个元素的最优解）。
转移方程：
初始化：dp[0] = 0（无元素时和为0）；dp[i] = ∞（初始化为无穷大，后续更新最小值）。
对于i从1到N：
反向遍历j从i-1到0（保证子序列aⱼ₊₁~aᵢ连续，且反向遍历可提前终止）：
计算sum_ji = sum(aⱼ₊₁~aᵢ)，max_ji = max(aⱼ₊₁~aᵢ)。
若sum_ji > B → 终止反向遍历（因j减小，sum_ji会更大，必然超过B）。
否则 → dp[i] = min(dp[i], dp[j] + max_ji)。
初始化：dp[0] = 0，dp[1..N] = ∞。
计算顺序：i从1到N（按元素个数递增，保证计算dp[i]时dp[j]已计算），j从i-1到0（反向遍历，提前终止优化）。
输出结果：dp[N]（前N个元素的最小最大值和）。
3. 优化技巧
提前预处理前缀和数组sum_prefix[i] = a₁+...+aᵢ，sum_ji = sum_prefix[i] - sum_prefix[j]，O(1)计算子序列和。
动态计算max_ji：反向遍历j时，max_ji = max(max_ji, a[j])（因j从i-1到0，a[j]是aⱼ₊₁~aᵢ的前一个元素，可累计最大值），避免重复遍历子序列求最大值。
四、详细步骤推导（以序列(2,2,2,8,1,8,2,1)，B=17为例）

1. 算法代码框架（含优化技巧）
2. 问题性质说明（考试答题模板）
最优子结构性质：设前i个元素的最优划分为P，最后一个子序列为aⱼ₊₁~aᵢ，则P的前j个元素的划分必是前j个元素的最优划分。假设存在更优的前j个元素划分P’，则P’ + [aⱼ₊₁~aᵢ]是前i个元素的更优划分，与P是最优划分矛盾，故最优子结构成立。
子问题重叠性质：计算dp[i]时，需多次用到不同j对应的dp[j]。例如，计算dp[6]和dp[7]时均用到dp[3]，无需重复计算dp[3]，可通过DP数组存储复用，体现子问题重叠。
六、改编思路拓展
改编方向1：限定子序列个数
题目修改：除了每个子序列和≤B，还要求子序列个数不超过K，求最小最大值和。
解题调整：状态定义改为二维dp[i][k]（前i个元素划分为k个子序列的最小最大值和），转移方程：dp[i][k] = min(dp[j][k-1] + max(a[j+1..i]))（sum(a[j+1..i])≤B，j从k-1到i-1），初始化dp[0][0]=0，最终输出min(dp[N][1..K])。
改编方向2：子序列和的下限约束
题目修改：每个子序列的和不仅≤B，还≥A（A≤B），求最小最大值和。
解题调整：转移方程中增加sum_ji ≥A的约束，即sum_ji ∈ [A,B]时才更新dp[i]，反向遍历j时需同时判断上下界，避免遗漏合法子序列。
改编方向3：最大值改为平均值
题目修改：将“子序列最大值的和”改为“子序列平均值的和”，求最小平均值和（平均值=子序列和/子序列长度）。
解题调整：状态定义不变，转移方程中替换为dp[j] + (sum_ji)/(i-j)，需注意浮点数计算，且反向遍历j时需计算平均值而非最大值。

def zero_one_knapsack(w, v, C):
    n = len(w)
    # dp[i][j]：前i个物品（0~i-1），容量j的最大价值（0索引适配）
    dp = [[0]*(C+1) for _ in range(n+1)]
    
    # 填充DP表格
    for i in range(1, n+1):
        for j in range(1, C+1):
            wi = w[i-1]
            vi = v[i-1]
            if j < wi:
                dp[i][j] = dp[i-1][j]
            else:
                dp[i][j] = max(dp[i-1][j], dp[i-1][j - wi] + vi)
    
    # 构造最优解（x[i]=1表示装入物品i+1）
    x = [0]*n
    j = C
    for i in range(n, 0, -1):
        if dp[i][j] != dp[i-1][j]:
            x[i-1] = 1
            j -= w[i-1]
    
    return dp[n][C], x

def max_result_with_operators(v, K):
    N = len(v)
    # 预处理前缀和数组
    sum_prefix = [0]*(N+1)
    for i in range(1, N+1):
        sum_prefix[i] = sum_prefix[i-1] + v[i-1]
    
    # 初始化DP表格：dp[i][k]表示前i个数字用k个乘号的最大结果
    dp = [[0]*(K+1) for _ in range(N+1)]
    for i in range(1, N+1):
        dp[i][0] = sum_prefix[i]  # k=0时全为加号，直接求和
    
    # 填充DP表格：k从1到K，i从k+1到N，j从k到i-1
    for k in range(1, K+1):
        for i in range(k+1, N+1):
            max_val = 0
            # j的范围：前j个数字至少能分配k-1个乘号（j ≥ k）
            for j in range(k, i):
                current = dp[j][k-1] * (sum_prefix[i] - sum_prefix[j])
                if current > max_val:
                    max_val = current
            dp[i][k] = max_val
    
    return dp[N][K]

def min_max_sum_partition(a, B):
    N = len(a)
    # 预处理前缀和数组
    sum_prefix = [0]*(N+1)
    for i in range(1, N+1):
        sum_prefix[i] = sum_prefix[i-1] + a[i-1]
    
    # 初始化DP数组
    dp = [float('inf')]*(N+1)
    dp[0] = 0  # 边界条件：无元素时和为0
    
    for i in range(1, N+1):
        current_max = 0  # 动态记录a[j+1..i]的最大值
        # 反向遍历j，提前终止（sum超过B时）
        for j in range(i-1, -1, -1):
            current_max = max(current_max, a[j])  # a[j]是a[j+1..i]的前一个元素
            sum_ji = sum_prefix[i] - sum_prefix[j]
            if sum_ji > B:
                break  # j减小，sum_ji更大，无需继续
            # 更新dp[i]
            if dp[j] + current_max < dp[i]:
                dp[i] = dp[j] + current_max
    
    return dp[N]
