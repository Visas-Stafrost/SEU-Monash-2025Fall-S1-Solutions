## ✨ 项目简介

欢迎来到 SEU-Monash 2025 秋季学期的学习资料仓库！📚

这里整理了本学期 **5 门核心课程** 的完整学习资料，包括：
- 📝 课堂笔记与知识点汇总
- 📚 课件与推荐教材
- ✍️ 作业与实验报告
- 🎯 考试复习资料（含 cheatpaper 精华版）

本项目由 **Fuα 协会** 成员 [Visas-Stafrost](https://github.com/Visas-Stafrost) 和 [Yu_Floyd](https://github.com/ThirstforSisyphus) 牵头，联合多位同学共同整理完成，凝聚了大家一整个学期的心血与智慧

**⚠️ 友情提示**：本仓库所有内容仅供学习交流参考，请勿用于商业用途。
