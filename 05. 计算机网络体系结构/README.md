# 课程介绍

本课程编号为 05 ，恶意最满的一门课。

## 授课教师

2025秋季学期任课教师为**周玲**老师。

- **老师介绍**: 苏黎世毕业的高材生，但似乎只授课不收学生。人非常刻薄，会用那种关心学生学习态度的口吻不停指责，但实际只能感受到知识分子对待身边人事物的傲慢，对待学生没有半点同理心。
- **教学风格**: 老师课讲的非常流水账，走马观花式科普类课程，上课也是脚踩西瓜皮滑到哪是哪，跟考研深度比不了， ppt 加起来一千多页，知识密度低的吓人。

## 考勤情况

- 一堂课（此处指 45 分钟）可以喊三十个人出来回答问题，属于点了名都不能偷偷跑的课。甚至有的哥们真的被点起来三四回还要被调查是不是帮没来的回答的。

## 课程内容

就是自顶向下那本书的讲的顺序把考研学的东西讲一遍，一半学过，但还是有不少地方不一样。

## 考核情况

唯一一门同时有
1. 超绝无情考勤乱斩
2. 每周布置问题要做 ppt 还要 pre 
3. 课程实验
4. 课程报告
5. 全英文考试（占比 60% ）————允许带一张 A4 cheatpaper，有选择，选择有语法有挖坑，大题得好好准备一下上课 ppt 里的那些设备关系图还有设计结构图
我甚至不知道前面那五个是怎么只分了 40% 的 point，老师极度厌恶 ai ，使用各种神奇妙妙小工具前务必把痕迹抹除干净。

## 仓库介绍

如果你要卷绩点（此处仅指想申海外组内没有合作基础的博），这门课将是你重点需要关注的课，因为分差拉的非常大，而且这课虽然没挂人，均分也是70多。申海外博的东南成绩单是没有所谓的规格化的，很多实验室会要求均分 80+ ，这门课真的会非常影响申博。所以对于申博来说这课真是又恶心又得认真搞，其他课其实拿 80 一点不难甚至 80 起，这课认真都有可能 60 ，而且老师打分会卡绩，完全没有任何同理心而言。

仓库会主要放考试的内容，lab其实就能在b站上找到教程，就是自顶向下那本书的课后实验属于，每周 ppt 的话给了没意义，问题可能不一样。报告自己想想办法吧。其实及格不难，但是协会里搞笔记都搞这么认真肯定不是奔着 60 或者 70 去的呀，笔者当时元旦回家没搞翻大车只拿了 70+ ，心灰意冷了，只放点电脑里还存着的文件，我是不想给这课再花任何时间了。
