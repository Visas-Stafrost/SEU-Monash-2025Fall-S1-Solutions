# 课程介绍

本课程编号为 04 ，本课程考试占比80%，注意考试就好。

## 授课教师

2025秋季学期任课教师为**方效林**老师。

- **老师介绍**: 人非常好，但是由于太好了导致出现了本来该百余人的课题只有个位数的人去上老师在群里摇人。
- **教学风格**: 老师课其实讲的很认真也很生动，笔者认为其实讲的比大部分学校的算法课清晰，奈何处在了一种程度上的末法时代。唉，本科的时候还在讨论前端好还是后端好，结果现在全被 AI 打爆了，以前本科跟电气的哥们天天喊上号的人也会冷不丁问我一句会不会时间序列预测。

## 考勤情况

- 有人帮忙撑撑场子不出教学事故的程度就行

## 课程内容

就是正常本科算法课的翻版，分治、贪心、动规那些，老师讲的很认真，跨专业没上过的同学可以听一听。

## 考核情况

纯大题七条，没有小题，题目中英对照没有语言关，答题伪代码和中文注释混杂，考试有难度，会有部分上课 ppt 原题，大部分就是贪心或者 dp ，图论就考那么一道，但是蒙这边直接开卷，貌似本部是三张cheetpaper。


## 仓库介绍

因为算法只考了 87 还没有本科同一门课考的高很伤心，而且把资料开源给同学同一套资料有人考到了 90 更伤心了，这个仓库就只放协会整理的一些资料，上课的 ppt 可以去老师个人主页下载，很全，但是 cheatpaper 里已经收录了 ppt 里的题。
